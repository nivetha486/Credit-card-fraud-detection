# Credit Card Fraud Detection Using Machine Learning

## Project Overview
This project uses supervised machine learning to classify credit card transactions as legitimate or potentially fraudulent.

## Technology Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Random Forest Classifier

## Features
- Upload transaction data using a CSV file
- Predict potentially fraudulent transactions
- Display prediction summaries and charts
- Download prediction results
- Display model evaluation metrics

## How to Run
1. Open the project folder in the terminal.
2. Activate the virtual environment if needed.
3. Run:

   `python -m streamlit run app.py`

4. Open `http://localhost:8501` in your browser.

## Dataset
Credit Card Fraud Detection dataset.

## Model Evaluation
The application displays accuracy, precision, recall, F1-score, and a confusion matrix.

## Note
Predictions are model outputs and should not be treated as definitive proof of fraud.
